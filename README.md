# SHOP MECACAO WEB

Greenfield local-first web app cho Shop Mẹ CaCao.

## Baseline hiện tại

**V0.1 — Foundation**

- Frontend: React + TypeScript + Vite + PWA
- Local API: Node.js + Express
- Database: SQLite (`data/shop.db`, không commit lên GitHub)
- Local production: `http://localhost:3000`
- GitHub Pages: DEMO/PREVIEW, không sử dụng dữ liệu thật

## Chạy lần đầu trên Windows

1. Cài Node.js LTS (Node 20+; khuyến nghị Node 22 LTS).
2. Chạy `scripts/SETUP_FIRST_TIME.bat`.
3. Khi báo `SETUP PASS`, chạy `START_SHOP.bat`.
4. Trình duyệt mở `http://localhost:3000`.
