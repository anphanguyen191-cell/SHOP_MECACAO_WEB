# SHOP MECACAO WEB

Greenfield local-first web app cho Shop Mẹ CaCao.

## Baseline hiện tại
**V0.1.1 — Foundation local setup patch**

- Frontend: React + TypeScript + Vite + PWA
- Local API: Node.js + Express
- Database: SQLite via built-in `node:sqlite`
- Local production: `http://localhost:3000`
- GitHub Pages: DEMO/PREVIEW
- Không yêu cầu Visual Studio Build Tools

## Windows — chạy lần đầu
1. Node.js 22+ (máy test hiện dùng Node 24).
2. Lấy source V0.1.1 mới nhất.
3. Chạy `scripts/SETUP_FIRST_TIME.bat`.
4. Khi báo `SETUP PASS`, chạy `START_SHOP.bat`.
5. Kiểm tra `http://localhost:3000` và badge `LOCAL`.
